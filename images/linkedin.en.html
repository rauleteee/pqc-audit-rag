WHAT'S NEW: TECHNOLOGIES ADDED AND WHAT THEY SOLVE
🔌
FastAPI
Before: only usable from the web UI or terminal.
Now: any program can request an audit.
📨
Kafka
Before: each audit blocked the request for minutes.
Now: it is queued and replies instantly with a ticket number.
⚙️
Worker
Before: one process both served and worked.
Now: separate workers; add more under load.
🐘
PostgreSQL
Before: jobs lived in memory and were lost.
Now: status and reports stored, queryable later.
🐳 Docker Compose
One command starts app, API, worker, Kafka, Postgres and Grafana.
🧪 Integration tests in CI
Every change tests the real flow with Kafka and Postgres.
⏳ Before: you requested an audit and waited with a blocked screen.
🎫 Now: you get a ticket instantly and fetch the result when it is ready.
