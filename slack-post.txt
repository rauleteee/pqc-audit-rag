Hey everyone 👋 I just wrapped up my LLM Zoomcamp final project and wanted to share it with the cohort — would love if you gave it a try and told me what you think!

🔐 *PQC Audit RAG* — it scans a Python codebase for quantum-vulnerable cryptography (RSA, ECC, DSA, Diffie-Hellman, Ed25519) and generates a cited, per-finding post-quantum migration plan. The idea: "you can't migrate what you can't see" → inventory → retrieved guidance → concrete plan.

▶️ *Live demo* (no install — paste a public repo URL or upload a .zip):
https://pqc-audit-rag.streamlit.app
Try scanning https://github.com/paramiko/paramiko 😉 (give it a few seconds to wake up)

⭐ *Code:* https://github.com/rauleteee/pqc-audit-rag

What's inside (course stuff you'll recognize):
• RAG over a curated PQC knowledge base (NIST FIPS 203/204/205, CNSA 2.0…)
• Hybrid search (RRF) + re-ranking + query rewriting, evaluated with Hit Rate / MRR
• LLM-as-judge to pick the synthesis prompt
• Runs 100% free & local (Ollama + ONNX) or any hosted API (Groq, OpenAI…)
• Monitoring with Postgres + Grafana (7 charts), full docker-compose stack, CI + SBOM

Built on the open-source pqc-audit engine. Any feedback — retrieval, prompts, UX, anything — is super welcome, and happy to answer questions about how it's put together. 🙏
